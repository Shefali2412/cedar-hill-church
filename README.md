# Cedar Hill Church – Sample Website

A clean, mobile-friendly church website I designed and built as a portfolio sample.
Cedar Hill Church is a fictional church.

🔗 Live site: https://shefali2412.github.io/cedar-hill-church/

## Features
1. Service times and "Plan your visit" section for newcomers
2. Services and ministries overview
3. Events list with category filters
4. Online giving form (demo)
5. Contact section with a message form (demo)
6. Responsive design with a mobile menu

## Built with
HTML, CSS and JavaScript
